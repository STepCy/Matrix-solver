# 👾 Matrix Calculator 👾

An advanced, responsive, and beautifully designed web application for performing complex matrix operations. It features **12 comprehensive operations** with visual step-by-step explanations and exact fraction representations.

ใช้งานเว็บเมทริกซ์คำนวณและแก้สมการได้ทันที ทุกที่ ทุกอุปกรณ์ ผ่านหน้าเว็บเบราว์เซอร์ของคุณ!

---

## 🛠️ Features

* **Cramer's Rule**: Solves systems of linear equations ($Ax = b$) and shows determinant steps.
* **Determinant**: Computes the determinant of any $n \times n$ matrix with cofactor expansion formulas.
* **Inverse Matrix ($A^{-1}$)**: Calculates the inverse and verifies the result using $A \cdot A^{-1} \approx I$.
* **Transpose ($A^T$)**: Instantly flips matrices across their diagonal.
* **Matrix Multiplication**: Computes $A \times B$ with dynamic dimension checks.
* **Eigenvalues & Eigenvectors**: Finds characteristic values and vectors for symmetric/real matrices.
* **Reduced Row Echelon Form (RREF)**: Solves matrices using Gaussian Elimination with clear step-by-step row operations ($R_i \leftrightarrow R_j$).
* **LU Decomposition**: Factors $PA = LU$ into lower and upper triangular matrices.
* **Rank & Nullity**: Calculates linear independence and dimension of the null space.
* **Trace**: Sums the main diagonal elements.
* **Adjugate Matrix**: Transposes the cofactor matrix.
* **Add/Sub**: Basic operations for same-dimension matrices.

---

## 💡 Special Functions

1. **⅓ Fraction Mode**: View exact fractional forms of all decimal solutions instead of floating points.
2. **🎲 Random Generator**: Populate grids instantly with random integers for quick testing.
3. **⌨️ Keyboard Navigation**: Use Arrow keys ($\leftarrow \uparrow \downarrow \rightarrow$) to navigate cells and `Enter` to jump to the next input.
4. **📱 Fully Responsive**: Modern dark-themed user interface optimized for desktop, tablet, and mobile devices.

---

Developed using HTML5, CSS3, and Math.js.
